# Original workbook inputs

Place the actual project workbooks here, retaining these names:

- `260316 Raw data - TP1.xlsx`
- `260316 Raw data - PS1.xlsx`

Both `quantification` and `analysis` sheets are used. Preserve the original identifiers, column names and row order: PostgreSQL analyte IDs depend on source row positions. This package contains the import scripts, not the workbook data. Do not substitute fabricated or reshuffled data for the measured inputs.

To keep workbooks elsewhere, set `TP1_FILE` and `PS1_FILE` to their paths. See [the loading guide](../../docs/INITIAL_DATA_LOADING.md).
